GT-SPORT OPTION 4 — PUBLISHING

This is a normal static website. It does not require an AI website builder.

FREE PUBLISHING OPTIONS:
1. GitHub Pages
   - Create a GitHub account and a new public repository.
   - Upload every file and folder from this package.
   - Open Settings > Pages.
   - Under Build and deployment, choose “Deploy from a branch”.
   - Select main and /root, then Save.

2. Cloudflare Pages
   - Create a free Cloudflare account.
   - Open Workers & Pages > Create > Pages > Upload assets.
   - Upload this entire folder.

IMPORTANT:
- Keep index.html, style.css, script.js, products.js, assets and shop together.
- The AI button is a built-in FAQ assistant. It does not call a paid AI service.
- Jersey images are local SVG illustrations and will display without external image links.
- Replace local SVGs later with approved supplier photos using the same filenames.
